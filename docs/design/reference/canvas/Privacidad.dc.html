Analítica

Cómo contamos visitas

Usamos Umami para saber qué artículos se leen. Registra la página vista, de qué sitio llegaste, el navegador, el sistema operativo, el tipo de dispositivo y el país. No usa cookies, no guarda datos que te identifiquen y no te sigue de un sitio a otro.

Si tu navegador envía la señal «No rastrear» o usas un bloqueador, no pasa nada: el blog funciona igual.

Tus datos

Qué datos personales tenemos

Cuenta: si creas una, tu correo, tu nombre de usuario y tu contraseña cifrada. La eliminas tú mismo cuando quieras desde Mi cuenta; tus comentarios quedan como «Anónimo».

Newsletter: si te suscribes, tu correo, solo para enviarte los artículos nuevos. Puedes darte de baja en cualquier momento.

Comentarios: el nombre y el texto que escribes, que se publican después de revisarlos. Las respuestas desde el fediverso llegan con tu dirección pública de Mastodon.
